**Why it worked (from the caption):**

- "Save it so you never stare at a blank first slide again" is an explicit save prompt aimed at a pain point.

### Formats to steal (adapted for DIY)

| Format | GetKnottyDIY carousel idea |
|---|---|
| List | "7 tools I bought before I knew what they did" |
| Before / after | The half-finished project vs. the "finished" one (finished is relative) |
| Myth busting | "Myths about DIY I believed until a stud finder humbled me" |
| Story | "I picked up a power tool for the first time in COVID. 5 years of projects later..." |
| Breakdown | Cost breakdown of one project: budget vs. what I actually spent |
| Mistakes | "Things I'd do differently" with the receipts |
| Beginner guide | "Which tool for which job," explained with sarcasm |
| Rating / ranking | Rank my unfinished projects by shame level |
| Day in the life | Software trainer by day, power tools by night |
| Resource drop | "Comment KNOTTY for my beginner tool list" (lead magnet / affiliate links) |

### Strategy notes
- Test a comment-to-get CTA tied to an affiliate list (tool list, supplies list) so it feeds brand-deal and affiliate goals.
- Lead with a number on the cover slide.
- End every carousel with a save prompt.
