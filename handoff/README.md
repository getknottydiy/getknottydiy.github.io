# Crew handoff folder
- `to-edit/` : scriptwriter drops `<slug>.md` briefs here (script, shot list, hook, captions).
- `edited/`  : video-editor writes `<slug>.md` here when the cut is exported.
The video-editor runs LOCALLY on Dana's Mac (Edits app + metapilot-native MCP). Everything else can run in the cloud.
